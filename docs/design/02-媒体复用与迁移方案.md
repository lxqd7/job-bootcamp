# 媒体复用与迁移实施方案

日期：2026-11-17；关联CRS-06/07。优先复用旧腾讯云VOD，不可用时使用少量有权使用的演示视频。视频本体不在业务MySQL；禁止整库迁移旧用户、交易、权益或进度。

## 1. 已有证据与限制

旧tj-media/TencentMediaStorage负责VOD资源查询及播放签名；Media保存fileId/mediaUrl/coverUrl/duration等元数据。旧学生端frontend/tj-portal/src/pages/learning/index.vue使用TCPlayer，appId曾写死，新系统必须由后端授权响应统一提供。一般文件COS/OSS适配不代表视频同时用这些存储。

2026-11-16抽样：旧库152条媒资、153条未删除视频小节关联；一条资源签名网关403，内部可签名但前端/签名appId不一致；腾讯API分别返回appid not match和file not exist。仅一条抽样，不能断言全部失效或已恢复。未完成播放器实际播放；临时测试账号/脚本已清理、启动服务已停止，未下载/删除云视频。

## 2. 迁移操作契约

1. 管理员提交课程/章/小节/media清单，先import-preview输出旧ID→新ID计划、重复项、缺关联及appId；不读取或展示旧云密钥。
2. import以batchId＋inputHash幂等，旧ID映射唯一。保存origin=OLD_IMPORT及provider/appId/fileId，不保存永久psign，不重复下载上传云文件。
3. verify查询真实资源元数据并做播放授权检查；AVAILABLE须有有效duration且实际授权链路可用，数据库记录存在不是验证成功。
4. 未验证PENDING、明确缺失MISSING、网络/配置异常ERROR；后台可筛选，学生端提示资源异常。课程付费上架至少有一个AVAILABLE视频小节；后续故障不撤用户权益。
5. 旧资源共享时删除仅解除本系统引用；首版无云DeleteMedia接口。不得为“清理”删除旧云文件。
6. 真正更换云账号才需文件迁移，必须有合法可访问源文件/导出权限；首版不自动执行。

## 3. 播放授权实现

MediaPort定义verify(MediaRef)、authorize(MediaRef,userId,expiresAt)、metadata；TencentVodAdapter和DemoMediaAdapter实现。Tencent使用腾讯官方VOD签名规范，生成appId/fileId/psign，SDK依赖在S03记录实际解析版本；不手写臆造SDK方法。密钥只环境注入；前端用TCPlayer，资源appId必须匹配。

POST play-authorizations验证登录、lesson→course→media真实归属及学习有效来源。授权有效120秒，前端提前30秒续签；每次续签重新验权。不提供匿名试看（旧isFree试看字段不迁移为权益），免费课也先领取；管理员预览使用独立管理权限入口，不经过学生API或长期公开链接。

退款冻结后不再签发新token。120秒仅约束本系统播放凭据的受理期限，不是VOD已建立播放、分片URL或缓冲的强制停止上限；其有效期由实际云播放器/资源策略决定，须在S03实测记录。前端获知权益失效即暂停并清授权，后台新进度仍验权；不能承诺收回已下载内容。

DEMO资源位于DEMO_MEDIA_ROOT私有目录，不能放前端public。授权返回短期签名URL，签名绑定userId/authSessionId/mediaId/playSessionId/expiry/nonce；每个Range请求校验签名、原会话仍有效及当前权益。原生video请求不要求额外Bearer头；该URL本身是短期访问凭据，不能声称绑定userId就无法被转发。支持HTTP Range/206/416、正确Content-Type/Content-Range，拒绝路径遍历、根目录外文件和过期签名。test视频由用户授权或明确可用许可提供；不伪造旧课程已迁移。

播放session由授权返回playSessionId绑定user/course/lesson/mediaVersion，进度API核对归属但不把客户端总时长当事实。服务端时长durationMs>0；上报position clamp到[0,duration]，严格position*2>duration完成；拖动可触发是已选规则，不另引入覆盖观看率。

## 4. 管理与验收

管理端媒体列表显示来源/状态/appId/fileId/时长/最后验证时间及错误类别，不显示密钥。import-preview将输入及hash存media_operation作为任务暂存，不写课程/媒体业务记录；import复用该输入，verify同表保存进度和结果，可由操作状态接口轮询。import报告逐资源结果；中途失败可重试未完成项，不因部分失败重复创建课程。删除目录保留历史ID和订单小节清单。

验收：授权正常播放/拖动/续期；无权益、退款后新授权拒绝；过期签名、错appId、缺资源、网络失败均有明确提示；DEMO私有路径不能直接访问且Range有效；重复导入不重复；删除不调用云删除；旧视频验证结果与演示视频分列。真实VOD凭据不可用时完成DEMO闭环，最终报告真实部分NOT_RUN，不写“视频全部可用”。
