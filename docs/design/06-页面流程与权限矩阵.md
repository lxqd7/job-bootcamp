# 页面流程与权限矩阵

日期：2026-11-17。Vue3＋TypeScript学生端和管理端（含教师工作区）。页面必须连接对应API，不能以静态演示绕过业务；实现时与该业务阶段一起完成，不最后一次补前端。

| /routes、/routes/:id | 成员/顺序、套餐价、已有课抵扣预览、福利说明 | 全部已有只显示按顺序学习，不伪造零元订单 | S03/S07 |

| /me/profile | 昵称/头像/密码 | 不能自行改角色 | S02 |

管理端：
- /admin/courses（含分类、目录、媒体）、/admin/routes：编辑、发布/下架、版本、发布错误定位；路线显示每课分摊及>=1元校验。
- /admin/users、/admin/teacher-assignments：单角色、启停、课程/路线分配；无赠送入口。
- /admin/assignments：正式作业草稿、预览、发布/下架；发布后编辑生成新版本。
- /teacher/courses、/teacher/questions、/teacher/submissions、/teacher/benefits、/teacher/notes：只显示当前分配范围，答疑、只读作答反馈、福利题维护与发布、优秀评选；无正式课程编辑/人工改分。S12-c 的福利题页复用 JSON 题面编辑，发布后展示路线/epoch 绑定。
- /admin/activities、/admin/coupon-rules、/admin/exchange-projects：三种券及单一范围字段联动、已发核心字段只读、库存限额/兑换价修改带版本确认。
- /admin/trades、/admin/refunds：异常筛选、查看业务状态、渠道查询和恢复；不提供“审核通过退款”或任意改金额。
- /admin/moderation：隐藏公开内容、匿名追溯、违规奖励撤回（必填原因），不开放全站私人笔记浏览。
- /admin/operations：服务处理积压与同事件重投；不任意改业务payload。dev场景控制独立标识，prod不出现。

## 2. 前端交互规范

钱由后端返回整数分，前端只格式化，不能自己算最终优惠；时间服务器UTC转Asia/Shanghai。ID全程string。Axios统一处理错误及traceId；单页刷新请求合并，多标签页用Web Locks串行刷新并用BroadcastChannel通知（支持这两种能力的浏览器完成验收）。access token仅内存；JS只读对应应用的csrf cookie，refresh cookie保持HttpOnly，具体会话协议见工程规范。

所有写按钮等待中禁用，同一次点击重试复用Idempotency-Key；用户修改内容再提交用新键。禁止组件自动重复付款或兑换。请求超时显示“结果确认中”并按业务ID查询，不直接提示失败让用户重复支付。

列表加载/空/错误/无权限四态分开；表单显示字段错误，409保留用户输入并提示刷新/合并。代码草稿自动保存防抖2秒，离页提示未保存；网络失败不覆盖本地编辑。视频每15秒及暂停/离页上报当前位置，失败可重试；完成阈值由后端判。

课程完成进度只算当前发布目录的视频小节；总小节0时progressPercent=null，页面显示“暂无视频”，不显示已完成或100%；作业单独显示已作答/未作答，不设锁课。代码提交成功立即算已作答，AI反馈状态独立。选择题未答可提交，弹一次未答数量确认；代码全空禁止提交。未发布作业显示“暂未发布”，不阻止购买。

结算金额变化必须重新确认；默认最优券可取消，手选无解须提示调整，不静默丢券。显示部分优惠仍整券消耗。退款按钮说明按服务器受理时点记录，网络未收到requestId时重试同幂等键查询原结果。

AI轮询2秒→30秒后5秒，离页停止；不展示Qwen/DeepSeek或底层报错。反馈只纯文本/安全转义。仅模拟功能及其结果显示mock标签；技术错误以可读状态呈现，不把服务名/数据库异常抛给学生。

## 3. 角色与数据权限

| 能力 | 学生 | 教师 | 管理员 |
|---|---|---|---|
| 商品介绍 | 已发布内容 | 已发布及负责教学内容 | 按管理权限 |
| 课程/路线/正式题维护 | 无 | 无 | course/route/assignment管理 |
| 学习/正式题/本人历史 | 课程ACTIVE权益＋本人 | 不兼学生不提交 | 不代学代答 |
| 学生正式作答和反馈 | 本人且有课程权益 | 当前负责课程只读 | 首版不默认全量读取学生作答 |
| 福利题维护 | 无 | 课程和开放路线均分配、epoch当前有效 | 全部福利题管理 |
| 福利作答/历史 | 课程权益＋至少一条匹配路线资格＋epoch资格 | 当前课程/路线范围内只读学生记录 | 管题权限不自动成为读学生答案权限 |
| 问答 | 有课程权益 | 负责课程答疑 | 公开内容治理 |
| 匿名真实身份 | 不向其他学生提供 | 默认不提供 | anonymous:trace＋reason＋审计 |
| 私人/采集笔记 | 仅本人，退款保留管理 | 不可看 | 首版不开放浏览 |
| 公开笔记与评优 | 有权益查阅/采集 | 负责课程公开原创可评优 | 治理公开内容、违规撤奖 |
| 点赞 | 有内容访问权、不可自赞 | 首版无入口 | 无入口 |
| 订单/退款 | 本人 | 无 | 排障/审计，不改自动资格标准 |
| 签到/领券/兑换/参榜 | 本人 | 无 | 配置规则，不代学生参与 |
| 教师分配/账号角色 | 无 | 无 | 对应管理权限 |

未列出的操作默认拒绝。管理员不提供私人内容治理或全量作答查看属于首版范围决定，不留开发模型自行扩权。公共课程下架不撤已购权益；题目下架禁止新提交但有权历史仍可看。

## 4. 服务端权限验收

网关身份和接口权限之外，每个资源服务验证真实课程/路线/作者归属。列表、详情、下载、内部接口与字段投影一致。媒体授权不能绕过学习权益；匿名作者不通过ID、头像URL或关联接口泄露。教师调离后旧页面新操作必须重新验范围并拒绝（已签发5秒scopePermit的在途操作按接口契约收尾），管理员有权限操作仍留审计。

并发授权：学习发5秒operationPermit前校验当前权益；先于退款冻结受理的请求可在到期前完成，冻结后的请求拒绝；题目下架和提交在作业库串行化。历史结果读取每次验权，不缓存长期许可。此边界须测试，不能声称微服务同步查询提供跨库原子性。

逐项验收：跨用户ID替换；教师跨课/路线；单课无福利；路线无课程权益；来源冻结但其他来源有效；退款个人笔记例外；旧版本下架；并发代码提交；匿名与私人内容；免费资源改价；移除前后用户福利差异。阶段S16按这些场景执行前后端共同验收。
