## 过程中发现并修复的问题

- 停止脚本第一次运行把 `ConvertFrom-Json` 的数组当成一个整体，导致 PID 和端口没有逐个处理，且错误地删除了 PID 文件。修复方式是显式枚举数组（`$json | ForEach-Object { $_ }`），然后对真实进程重新测试，停止与端口释放均通过。启动脚本的“已有进程仍存活”检查也同步采用相同写法。
- 在 Bash 中把启动脚本的输出用 `| tee` 接管道时，常驻子进程会继承管道句柄，调用方等待 EOF 不返回；改为把输出重定向到文件后，脚本 8.7 秒正常返回。正常 PowerShell 终端不受影响；自动化调用时应重定向输出而不是接管道。
- MySQL 检查最初把原生 stderr 包成 PowerShell 错误对象，输出冗长；改为抑制 stderr，只输出固定可读文案并保留退出码。
