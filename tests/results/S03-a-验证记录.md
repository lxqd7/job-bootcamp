# S03-a 验证记录

日期：2026-11-19（Asia/Shanghai）

## 范围

需求依据 CRS-01/02/02A、AUTH-03/04（课程管理权限）与任务书 S03-a：分类树/闭包、课程/章/小节 CRUD、课程管理页、学生列表/详情、MySQL 搜索。路线版本、价格分摊与教师分配属于 S03-b；媒体导入与付费课程发布前的真实视频校验属于 S03-c。

## 交付内容

- Flyway V2：
  - `category_closure`：祖先-后代闭包，分类变更后重建。
  - `course`：标题、描述、分类、价格、免费标记、状态（DRAFT/ONLINE/OFFLINE）、封面、目录版本、修订。
  - `chapter`、`lesson`：逻辑删除、排序、视频小节 mediaId 可空。
- 课程服务：
  - 分类创建/更新、防环、闭包重建、公开树与管理树。
  - 课程创建/更新/上下架、章节/小节创建/更新/删除、修订冲突。
  - 公开课程列表/详情、关键词与分类子树搜索（闭包）；草稿课程不出现在学生端。
  - 付费课程发布前必须有带 mediaId 的小节；免费课程按 CRS-02A 不要求视频。
  - 管理端 `/api/v1/admin/**` 通过 user 内部会话校验，要求 ADMIN 且包含 `course:manage`；不信任身份头，直连课程服务无 token 也会 401。
- 网关路由拆分：`/api/v1/admin/users/**` 到 user，`/api/v1/admin/courses|categories|chapters|lessons/**` 到 course。
- 演示数据：Java → 基础语法/并发编程 分类；免费课程“Java 入门体验”（已上架）；付费课程“Java 并发实战”（草稿）。
- 前端：
  - 学生端 `/courses`、`/courses/:id`：分类/关键词筛选、分页、课程目录。
  - 管理端 `/admin/categories`：分类树、新建/编辑。
  - 管理端 `/admin/courses`、`/admin/courses/:id`：课程创建/编辑、上下架、章节与小节的增删改。

## 过程中发现并处理

- 网关原先把 `/api/v1/admin/**` 全部路由到 user，会把课程管理接口错送；已拆分为 user 的 `/admin/users/**` 与 course 的管理路径。
- 分类闭包采用“变更后全量重建”的实现，当前分类数量很小；后续数据量上来后可改为子树增量更新。
- 终端里 MySQL 客户端显示中文标题乱码是控制台编码问题，API JSON 与页面显示正常。
- 章节/小节更新和删除已带 revision 校验；课程发布/下架同样使用 revision。

## 未验证或受限项

- 媒体/VOD 与 DEMO 播放适配、媒体导入幂等和付费课程“有效视频”校验属于 S03-c；当前付费发布只检查 mediaId 是否存在。
- 路线版本、套餐分摊、每付费课 ≥1 元校验、教师分配属于 S03-b。
- 课程详情 `isOwned` 固定 false，学习权益在 S05 接入。
- 课程管理授权采用“每请求调用 user 内部会话校验”，不是课程服务本地验 JWT；后续可按设计增加 Redis 会话缓存/本地校验。

- 浏览器只在应用内预览浏览器验证；测试课程/分类数据留在演示库中。
