### 7. 理解问题与精简回答

1. **为什么演示种子通过 API 而不是直接插 SQL？** 这样种子经过与真实用户相同的校验、事务、版本和权限路径，能发现“只有直插数据库才能成立”的假闭环；只有积分/债务等测试夹具直接改库，并明确标注用途。
2. **为什么安全矩阵要同时覆盖 401 和 403？** 401 表示未认证，403 表示已认证但角色/范围不足；两者混用会掩盖“普通学生被当成未登录”或“管理员权限被错误继承”的问题。
3. **为什么 DTO 敏感字段要递归扫描而不是只看类型定义？** 序列化框架、嵌套对象和旧字段容易让密码哈希、内部 token 或 AI prompt 从非预期层级泄漏；对真实响应做递归检查更接近攻击者视角。
4. **为什么需求族矩阵保留 NOT_RUN？** 真实支付/云媒体/模型账号没有凭据时不能伪造 PASS；NOT_RUN 明确区分“本地闭环已验证”和“真实外部联调未执行”。
