# S02-b 验证记录

日期：2026-11-19（Asia/Shanghai）

## 范围

需求依据 AUTH-01/04 与任务书 S02-b：Gateway 路由、服务端资源 JWT 校验、内部凭据、白名单/CORS/CSRF、教师和管理员账号管理。

## 交付内容

- 新模块 `bootcamp-contracts`（无 Spring 依赖）：`InternalTokenCodec`（HMAC-SHA256 服务凭据，60 秒、audience + operation 白名单）、`SessionCheckResponse`。
- 新模块 `bootcamp-gateway`（18080，Spring Cloud Gateway `server-webflux` 5.0.4）：
  - 静态路由：`/api/v1/auth/**`、`/api/v1/me`、`/api/v1/admin/**` → user；`/api/v1/categories`、`/api/v1/courses`、`/api/v1/routes` → course。
  - 公共白名单：登录/注册/刷新/退出、已发布课程与分类、健康；其余 `/api/v1/**` 需要 access token。
  - 受保护请求先调用 user 内部 `/int/v1/sessions/check` 校验会话；认证服务不可用时 fail closed 返回 503。
  - 删除客户端提供的 `X-User-Id`、`X-User-Role`、`X-User-Name`、`X-Session-Id`、`X-Service-Token`；不向下游注入身份头。
  - `/int/v1/**` 不暴露，返回 404；错误体使用统一 `code/message/data/traceId`，响应带 `X-Trace-Id`。
  - CORS 仅允许 `http://localhost:15173`、`http://localhost:15174`，允许 Authorization、Content-Type、X-CSRF-Token、X-Client-App。
- user 服务：
  - `SessionValidator` 复用 JWT/会话/用户/tokenVersion 校验。
  - `POST /int/v1/sessions/check`，由 `InternalAuthInterceptor` 校验服务凭据（aud=bootcamp-user，operation=sessions:check）。
  - 管理员账号管理：`GET/POST /api/v1/admin/users`、`PATCH /api/v1/admin/users/{id}`；需要 ADMIN 角色 + `user:manage` 权限。
  - 管理员可创建教师/管理员账号；不能通过管理接口创建学生；禁用或更改角色会递增 tokenVersion 并撤销该用户全部会话；禁止管理员禁用自己或修改自己的角色。
  - 分页使用 MyBatis-Plus `PaginationInnerInterceptor`。
- 配置：`INTERNAL_TOKEN_KEY` 本地缺省为 dev 占位值；生产必须用环境变量注入。当前使用静态路由，Nacos 与 Redis 未接入。

## 验收结果

`tests/acceptance/s02b-gateway-api.sh` 共 37 项全部通过，日志见 `S02-b-api-acceptance.log`：

- 公共路由：网关健康、分类无 token 可访问；`/me` 无 token 401；内部接口经网关 404；内部接口缺服务凭据 401。
- 登录与身份：经网关登录、`/me` 返回本人；带伪造 `X-User-Id/X-User-Role` 仍返回本人；无 token 只带伪造头 401。
- 刷新：经网关轮换 refresh，新 access 可用。
- 内部凭据：合法服务 token + 有效 access → active=true；非法服务 token → 401。
- 角色隔离：学生、教师访问管理用户列表 403；管理员 200。
- 账号生命周期：管理员创建教师、教师可登录但不能进管理接口、禁用后旧会话 401 且不能登录、重新启用后可登录；管理员把教师改为 ADMIN 后旧会话立即失效，新角色登录后可进管理接口；管理员不能创建学生、不能禁用自己。
- CORS：学生端来源的预检响应包含 `Access-Control-Allow-Origin`。

## 过程中发现并修复

- Boot 4 的 WebFlux starter 不提供 `WebClient.Builder` 自动配置，改为直接 `WebClient.builder()`。
- Gateway 5 的配置前缀是 `spring.cloud.gateway.server.webflux.*`，旧前缀不会加载路由。
- 过滤器中 `switchIfEmpty` 挂在整条 `flatMap` 链后，响应已转发成功时也会被当作空结果写 503；改为在会话检查 Mono 上用 `Optional` 显式表达“无结果”，避免在响应已提交后写错误。
- 验收脚本最初用学生端 clientApp 登录教师账号，返回 403 是正确行为；脚本改为使用管理端 clientApp。
