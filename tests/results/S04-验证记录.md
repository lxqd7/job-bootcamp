## 交付内容

- 新增 `bootcamp-marketing` 服务：端口 18087，独占逻辑库 `bc_marketing`；网关新增 `/api/v1/me/points`、`/api/v1/me/points/**` 路由，且排在用户服务通用 `/me/**` 路由之前。
- Flyway V1：
  - `points_account`：可用余额、待扣回债务、revision，余额与债务均非负。
  - `points_ledger`：业务类型、业务键、奖励分、余额/债务/月榜增量、变更后余额、业务日期、业务月、发生时间、结果码；唯一键 `(type,business_key)`。
  - `points_day_quota`：用户/业务日累计视频积分，0～50。
  - `points_month`：`(month,user_id)` 月榜分数与 revision，按分数降序、用户 ID 升序建索引。
  - `outbox_event`：事件外壳、payload、状态、attempt、next_retry_at、lease_token/lease_until。
  - `inbox_event`：`(consumer,event_id)` 主键、业务键、payload hash、状态。
- 积分写入：
  - 视频奖励先按 `(userId,lessonId)` 查业务键，事务内锁账户，再锁日额度，计算 `min(奖励, 50-当日已得)`。
  - 债务优先抵扣：`offset=min(debt,reward)`，余额只增加 `reward-offset`，月榜仍增加完整奖励。
  - 按 `Asia/Shanghai` 从事件发生时间推导业务日和业务月；跨月迟到仍写入原发生月。
  - 日限额为 0 时保留一条 `SKIPPED_DAILY_CAP` 的 0 分流水，后续重试不会补发。
  - 同事务写 `marketing.projection-changed.v1` outbox 事件。
- inbox 幂等：同一 `eventId` 不重复执行 handler；同一业务键换 eventId 由账本唯一键拦住；同一 eventId 被换成另一个业务键返回 409。
- outbox 扫描：`FOR UPDATE SKIP LOCKED` 领取，租约 30 秒，attempt 递增，5s/30s/2m/10m/30m 退避，10 次后转 `NEEDS_ATTENTION`；发送成功需 lease 仍匹配才标 `SENT`。
- 传输：默认 `none`，不伪造 MQ；`RabbitEventTransport` 在 `OUTBOX_TRANSPORT=rabbit` 时使用 topic exchange、持久消息和 publisher confirm。本机已用 RabbitMQ 3.13.7 + Erlang/OTP 26.2.5.16 补验真实投递。
- 测试专用接口（`POINTS_TEST_API_ENABLED=true` 才注册，默认 false）：
  - `POST /dev/points/rewards`：模拟学习完成事件，经过 inbox 与积分处理器。
  - `POST /dev/points/fixtures/debt`：设置测试用户待扣回债务。
  - `GET /dev/points/fixtures/accounts/{userId}`：读取余额/债务/月分/账本数/outbox 状态。
  - `POST /dev/outbox/relay`：手动触发一次租约扫描。
- 学生接口：`GET /api/v1/me/points`、`GET /api/v1/me/points/ledger`；管理员/教师返回 403，未登录 401。

## 过程中发现并处理

- Boot 4 不再自动提供 Jackson 2 `ObjectMapper`，改为固定字段 JSON 拼接，避免引入重复序列化栈。
- 月分查询 `COALESCE(score,0)` 在无行时返回空结果，导致并发下 NPE；改为 `COALESCE(MAX(score),0)`。
- 并发首次创建账户/日额度行与后续加锁在同一事务产生死锁；改为用独立 `REQUIRES_NEW` 事务按固定顺序预建行，再进入锁账户→锁额度→更新月榜的主事务。
- 并发同小节不同 eventId 曾可能在唯一键冲突时把外层事务标记回滚；在账户锁内二次查询业务键，冲突前返回已处理结果。
- 测试 eventId 换业务键原先会静默给新小节发分；改为校验 inbox 业务键并返回 409。
- `spring.rabbitmq` 健康检查在无 broker 时会拖垮 health；设置 `management.health.rabbit.enabled=false`，默认不连接。

  - MySQL `points_month` 为权威数据；只统计 `score > 0` 的学生。
  - `ROW_NUMBER() OVER (ORDER BY score DESC, user_id ASC)`，同分按用户 ID 升序，不并列。

  - 用户服务新增内部批量接口 `POST /int/v1/profiles/batch`，最多 100 个用户，使用 `profiles:batch` 服务凭据。

  - 月榜：ZSet `bc:dev:board:{month}:rank`，score 为负积分，member 为 20 位补零 userId；同分按 member 字典序即 ID 升序；names hash 和 revision 元数据。

  - 缓存按 `SUM(points_month.revision)` 判断新鲜度；积分变化后自动重建。
  - Redis 故障或删除 key 时回退 MySQL，结果正确优先。
